# ML Phishing URL Detector

A small Python project for checking URLs for common signs of phishing.

## About

I made this project to practice Python and learn more about basic cybersecurity concepts.

## Features

- Checks URLs for suspicious patterns
- Detects IP addresses used in URLs
- Checks for unusual URL characters
- Looks for common phishing-related words
- Gives a simple risk score
- Shows reasons for the result

## Technologies

- Python 3
- Regular Expressions
- urllib

## How to Run

Run the following command:

python phishing_ml.py

Then enter a URL when prompted.

## Note

This project is for learning and educational purposes. It is not a replacement for professional security tools.
